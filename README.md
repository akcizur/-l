# Windows 98 AI Desktop Remaster

Static GitHub Pages build based on the supplied Windows 98 AI Desktop prototype.

## Features
- Boot / shutdown sequence
- Functional window manager
- Minimize / maximize / focus / taskbar
- Desktop icon drag + persistence
- Start menu + Settings
- Virtual filesystem Explorer
- Notepad persistence and save
- Calculator with expression parser
- AI Buddy offline mode + optional server proxy
- Context menu
- Keyboard shortcuts
- CRT scanline option
- Responsive small-screen sizing

The browser build does not expose an AI provider secret. Configure a server-side proxy in Settings for live model calls.
